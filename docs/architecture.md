# 架构

## 总体

```
┌──────────────────────────┐        本地 IPC         ┌────────────────────────────┐
│ Rime 前端（小狼毫/鼠须管） │  ◄──────────────────►  │ 常驻进程 wubi86d（第 3 步起） │
│  librime + 本方案 + Lua    │  只做同步、快速的事     │  模型 / 语音 / 扩展插件       │
└──────────────────────────┘                         └────────────────────────────┘
```

**输入法内（Lua）只做同步、毫秒级的事**：查表、过滤、排序、读取常驻进程已经算好的结果。Rime 的 Lua 过滤器在按键路径上同步执行，任何网络或模型调用都会直接卡住打字。

**常驻进程负责一切慢的或需要权限的事**：本地模型推理、录音与语音识别、扩展插件。它不在的时候，输入法照常工作，只是没有这些增强。

## 分层

| 层 | 位置 | 依赖模型 | 内容 |
|---|---|---|---|
| 基础 | `schema/` | 否 | 五笔86、拼音混输、编码提示、用户词频 |
| 记忆与纠错（第 2 步） | `schema/lua/` | 否 | `wubi_memory.lua`：记录"用拼音打出来的字"作为薄弱字，五笔打到时提示完整编码；常见错码映射（待做） |
| 模型增强（第 3 步） | 常驻进程 | 是 | 候选重排、整句联想；异步计算，超时则回退 |
| 语音（第 5 步） | 常驻进程 | 是 | sherpa-onnx + SenseVoice/Paraformer，模型由用户自行下载 |
| 扩展（第 6 步） | 常驻进程插件 | 视插件 | 提示词片段、本地脚本 |

## 常驻进程与输入法之间的接口

常驻进程 `wubi86d`（`helper/`，Go 编写，单个可执行文件）与输入法之间**只通过文件交换数据**，都在 `<Rime 用户目录>/wubi86d/` 下：

| 文件 | 谁写 | 内容 |
|---|---|---|
| `context.txt` | 输入法（Lua） | 第 1 行序号，第 2 行刚上屏的文字，第 3 行最近的上文 |
| `suggest.txt` | wubi86d | 第 1 行对应的序号，第 2 行当前资料文件夹名，之后每行一个联想词 |
| `profile.txt` | 输入法快捷键 / `wubi86d use` | 当前使用的资料文件夹名，空表示只用输入历史 |
| `folders.txt` | wubi86d | 可切换的资料文件夹名，供快捷键轮换 |
| `config.json` | 用户 | 模型、资料文件夹、是否记录输入历史 |
| `index/` | wubi86d | 向量索引（输入历史一份，每个资料文件夹各一份） |

选择文件而不是本机 HTTP 的原因：

- **不开任何端口**，其它程序无法通过网络向输入法注入内容或读取上文；
- Lua 端只需读写小文件，Rime 自带的 Lua 环境就够用，不依赖网络库；
- 所有写入都是"写临时文件再改名"，读方不会读到半截内容。

**输入法从不等待模型**：上屏后 Lua 写出 `context.txt` 就返回；wubi86d 轮询到新序号后检索、生成，写出 `suggest.txt`；Lua 在之后的按键中读取，序号对得上才显示，所以旧联想不会错位出现。实测 M4 Max 上 qwen2.5:7b 热启动后续写 0.1–0.25 秒，通常在用户打下一个词之前就已算好。

### 联想流程（RAG）

1. 上屏文字攒成句子（遇到句末标点或满 60 字），求向量后存入输入历史索引（可在 `config.json` 关闭 `history`，`wubi86d forget-history` 清空）。
2. 资料文件夹每 5 分钟增量索引一次：只为新增或改动的 `.md` / `.txt` 文件求向量，已删除的文件移出索引。
3. 新上文到来时，用最近 32 个字检索输入历史和当前资料文件夹，取相似度足够高的几段作为参考，连同上文交给本地模型，要求输出若干 1–8 字的词语。
4. 输入法在用户开始打下一个词时，把五笔词码、全拼或拼音首字母能匹配当前输入码的联想词插到第 2 位起。首选不动，保留五笔简码按空格上屏的习惯。

### 隐私原则

- 模型地址默认只允许本机（`127.0.0.1` / `localhost`），配置成其它地址会拒绝启动，除非显式设置 `allow_remote`。
- 只记录上屏结果，不记录按键过程；数据只在本机用户目录。
- 系统密码框会禁用输入法，密码不会经过这里。

### 以后的扩展（第 6 步）

提示词片段、本地脚本等扩展同样走"文件约定 + 常驻进程"的方式。能执行脚本的扩展本质上就是键盘记录器的攻击面，所以扩展必须声明权限（网络、文件路径、执行），默认全部拒绝。
